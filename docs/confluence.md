# Выгрузка в Confluence

На странице `/wiki` кнопка «Выгрузить для Confluence» (или `GET /api/wiki/export`) отдаёт `gde-napisano-confluence.zip`:

- `storage/*.xml` — страницы в формате хранения Confluence: корень «Где написано? Регламенты», под ним по странице на регламент и страница «Разъяснения службы качества». У каждого пункта якорь (`p-5.2.2`), разъяснение ссылается на пункт, пункт — на разъяснения по нему.
- `html/*.html` — те же страницы обычным HTML со ссылками между собой, начало в `html/index.html`.
- `manifest.json` — порядок и иерархия страниц.

## Импорт через REST API (Confluence Cloud и Data Center)

1. Создать пространство или выбрать существующее, запомнить ключ (например, `GN`).
2. Получить API-токен: Cloud — id.atlassian.com → Security → API tokens; Data Center — личный токен доступа (тогда в `CONFLUENCE_USER` логин, в `CONFLUENCE_TOKEN` токен).
3. Проверить, что будет создано:
   ```
   python scripts/confluence_upload.py gde-napisano-confluence.zip --dry-run
   ```
4. Загрузить:
   ```
   CONFLUENCE_URL=https://<сайт>.atlassian.net/wiki CONFLUENCE_SPACE=GN \
   CONFLUENCE_USER=<почта> CONFLUENCE_TOKEN=<токен> \
   python scripts/confluence_upload.py gde-napisano-confluence.zip
   ```
   Страницы с теми же названиями обновляются новой версией, поэтому выгрузку можно повторять после изменения регламентов или базы разъяснений.

## Вручную

Создать страницу, открыть `html/<регламент>.html` в браузере, скопировать содержимое и вставить в редактор Confluence. Ссылки между страницами при ручном переносе придётся поправить; через REST API они сохраняются.

## Ограничения

- Загрузка проверена тестами на подставном сервере, на настоящем Confluence не проверялась.
- Названия страниц должны быть уникальны в пространстве: если там уже есть страница с названием регламента, она будет обновлена.
