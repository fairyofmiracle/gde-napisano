# Сертификаты для GigaChat

GigaChat проверяет TLS по цепочке с **корневым сертификатом НУЦ Минцифры**. Без него клиент часто падает с ошибкой SSL.

## Что положить сюда

Скачайте файл корневого сертификата НУЦ Минцифры и сохраните как:

```
certs/russian_trusted_root_ca.pem
```

Официальный источник: сайт Госуслуг / Минцифры (раздел про российские TLS-сертификаты). Файл должен быть в формате PEM (`-----BEGIN CERTIFICATE-----` …).

`*.pem` в git не коммитится (см. `.gitignore`) — на машине и в образе сертификат подкладывают отдельно.

## Как указывает приложение

В `.env`:

```env
LLM_PROVIDER=gigachat
GIGACHAT_CREDENTIALS=...   # ключ из личного кабинета
GIGACHAT_SCOPE=GIGACHAT_API_PERS
GIGACHAT_MODEL=GigaChat
# Пусто = искать certs/russian_trusted_root_ca.pem
# В Docker обычно монтируют в /certs/...
GIGACHAT_CA_BUNDLE=
```

Если файл лежит не в `certs/`, задайте полный путь в `GIGACHAT_CA_BUNDLE`.

## Проверка

После настройки проверьте, что простой запрос к модели проходит без SSL-ошибок. Если сертификат не найден или битый — приложение сообщит об ошибке конфигурации LLM, а не «тихо» уйдёт в Ollama.
