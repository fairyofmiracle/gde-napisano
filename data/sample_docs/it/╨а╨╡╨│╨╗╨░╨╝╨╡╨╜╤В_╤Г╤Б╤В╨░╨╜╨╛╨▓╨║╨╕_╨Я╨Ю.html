Регламент установки ПО

3. Программное обеспечение

3.1. На рабочих компьютерах разрешено использовать только программное обеспечение из утверждённого стандартного перечня.

3.2. Установка программы, которой нет в стандартном перечне, возможна по заявке в ИТ-поддержку после согласования руководителем и службой информационной безопасности.

3.3. Покупка лицензий на новое программное обеспечение проводится через заявку на закупку по Регламенту закупок.
