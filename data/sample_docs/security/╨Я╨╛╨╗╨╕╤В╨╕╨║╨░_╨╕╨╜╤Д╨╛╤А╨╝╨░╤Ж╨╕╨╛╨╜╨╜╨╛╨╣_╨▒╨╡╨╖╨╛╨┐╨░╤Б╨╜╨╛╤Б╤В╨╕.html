Политика информационной безопасности

3. Правила для работников

3.1. При получении подозрительного письма (фишинг) не переходите по ссылкам, не открывайте вложения и перешлите письмо на адрес security@example.corp.

3.2. Копирование рабочих файлов на личные флешки и другие съёмные носители запрещено. Допускаются только учтённые корпоративные носители.

3.3. Вынос рабочего ноутбука и другой техники из офиса допускается по пропуску на вынос материальных ценностей, согласованному руководителем.

3.4. Вынос оригиналов документов из офиса допускается только с письменного разрешения руководителя.
